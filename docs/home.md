# Home
The home view is where you can see a quick summary of the curreny select expense you have in the Expense View.
Gives you a little bit of an insight on how much you are spending per **Category and Payment Channel**

![Expense Tracker][home-view]

## How to Install

Simply go to the [release page](https://github.com/AlsonEntuna/ExpenseTracker/releases/)
and run the `ExpenseTracker_Installer.exe`. Make sure to install it to the
directory you want.
