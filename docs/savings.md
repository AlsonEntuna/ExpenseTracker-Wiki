# Piggy Bank

It's a simple savings tracker where you can put all the things you want to save up for in.

![PiggyBankWindow][piggy-bank-main]

## Creating a new Savings Goal
Just click on `Add New Savings` and you'll get a new window which you should fill up with descriptions

![Create Savings][piggy-bank-create]

Once you're happy just click on `Add Savings`

You can put several items that you want to save up for in multiple currencies for example.

### Adding an amount
![PiggyBank Add][piggy-bank-add]
When adding an amount, just click on the `+` sign and the tool will create an empty entry for this with the amount set to 0
and the date when it was added. The Progress will automatically be updated.
